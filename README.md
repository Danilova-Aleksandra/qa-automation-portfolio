# QA Automation Portfolio

A hands-on QA Automation portfolio project built with Python.

## Project Goals

This repository demonstrates practical skills in software test automation, including:

- Writing automated tests with Python and pytest
- UI test automation with Playwright
- REST API testing
- Running automated tests in CI/CD with GitHub Actions

## Tech Stack

- **Language:** Python
- **Test Framework:** pytest
- **UI Automation:** Playwright (planned)
- **API Testing:** REST API (planned)
- **CI/CD:** GitHub Actions (planned)

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Danilova-Aleksandra/qa-automation-portfolio.git
cd qa-automation-portfolio
```

### 2. Create and activate a virtual environment

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Install pytest

```bash
python -m pip install pytest
```

### 4. Run the tests

```bash
python -m pytest -v
```
